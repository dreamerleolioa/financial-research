# 主動式 ETF 區間觀察

## 介面與狀態

`/active-etf` 共用入口，以 `mode=daily|range` 切換單日與區間子頁面。
單日保留基金變化／個股共識，區間提供自訂起訖、近一週（7 個日曆日）、近一個月（30 個日曆日）與個股明細。
快捷期間以最新儲存快照日期為結束日，不使用電腦當天日期。

URL 保存共享個股搜尋 `q`、單日 `date`／`view`、區間 `start`／`end`、展開個股 `stock`。
重新整理和瀏覽器上一頁可還原這些條件。區間明細跳至單日時使用該個股完整代號；「返回區間觀察」還原原搜尋與區間。
基金變化原有的「搜尋標的或基金」仍是該檢視自己的篩選。

## 區間 API

`GET /active-etf-holdings/range` 使用現有登入保護，只讀取已保存的 MoneyDJ 快照，不觸發刷新。

- `start_date`、`end_date`：可選 ISO 日期，起日不晚於迄日，含首尾最多 366 個日曆日。
- 省略結束日取最新快照日，省略開始日取結束日前 29 天。
- `symbol`：可選完整個股代號，指定時才回傳該股每日 `timeline`；未指定時只回傳各股逐基金摘要，避免完整持股歷史一次傳到前端。
- `available_dates` 提供最近 366 個已儲存資料日；這是選單資訊上限，不是資料刪除政策。
- 完全沒有歷史快照回 404；已有歷史但指定區間無快照回 200，`observed_dates` 與 `stocks` 為空。
- 單日 API 接受選單最近 60 日以外的已儲存日期，供區間明細追查，並將選取日加入日期選單。

## 計算口徑

每檔基金使用區間內第一份與最後一份快照，不將區間外快照帶入期初。
列表包含區間內曾持有的股票，也包含股數未變的股票。
僅一份快照時，淨股數與權重差為 null；不可解讀成零變化。

第一份快照為基準，不計入增加、減少、新增或退出天數。之後沿各基金實際相鄰快照計算：

- 股數淨增減為期末減期初；權重差為百分點差。
- 增加／減少天數是該基金出現正／負股數差的比較日數；新增／退出天數分別是其中一部分。
- 先增加再減少可得到淨變化零，但增減天數仍保留。
- 不跨基金加總股數或權重，因各基金實際起訖與缺口可能不同。
- 完整快照中缺少該股代表未持有；缺少整份基金快照不能當成未持有。
- 缺口以同區間其他啟用基金有 MoneyDJ 快照的日期為參照，不推測各市場交易日，也無法由此判定全體來源同時中斷。
- 跨缺口的差額歸在下一份快照日，不能宣稱缺口內逐日持股已知。

每日明細保留股數、權重、前期資料日、來源 URL 與擷取時間。來源連結可能顯示供應者最新頁面，快照數值以儲存日期為準。
基金規模影響沿用既有單日估計，不等同已證實申贖。持股與權重變化不代表成交買賣超，也不加入 Daily Radar 評分。
